# AGENTS.md — Agent Note

Agent Note 实质上是由 agent 撰写的 RFC：持久的提案和决策记录，保留理由、备选、后果和所需核验。遵循[文档规范](../../docs/AGENTS.md)和 [Agent Note 规则](README.md)。

**每一份新的 Agent Note 都要触发一次取代检查。** 在现行树里搜索覆盖同一决策或机制的旧 note，用 [`dsh-archive-agent-notes`](../skills/dsh-archive-agent-notes/SKILL.md) 判定全部或部分取代，并在同一 PR 里归档每一个合格的已实现三联。部分取代的 note 保持现行并交叉链接。

[`已归档/`](已归档/AGENTS.md) 下的文件是冻结的历史快照：绝不要编辑它们，也绝不要当作当前权威。
