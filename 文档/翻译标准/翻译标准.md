# 词表
当前文档所在目录下,按首字母分
命名:`?.json`,如`a.json`
键为英文（纯小写），值为中文

# 数量要求
一个ts文件对应一个py文件,不能多也不能少

# 文件汉化
如果这个文件夹里包含汉化过的子项名,则必须有`translatemap.json`
内容为:(不包含拓展名,不包含上层路径)
```json
{
    "原名称":"新名称"
}
```

错误示范1:
```json
{
    "原名称.ts":"新名称.py"
}
```
错误示范2:
```json
{
    "文件夹/原名称":"文件夹/新名称"
}
```
以下这些文件不参与翻译体系的追踪:
* index.ts
* bin.ts
* __init__.py
* __main__.py
* README.md
* README.zh.md
* *.i18n.*

以下这些固定翻译直接使用,不写入`translatemap.json`
```json
{
    "client":"客户端",
    "value":"值",
}
```
