# @deepseek-ai/dsh-config-editor

## 概述

将插件配置保存到当前配置档的补丁并立即应用。写入在改动磁盘前验证完整候选值，并与配置档更改及热更新串行执行。无效值和更高层覆盖不会改动文件。

## 使用此包

在具有加载器和 profileContext 的配置档应用中挂载此服务。没有配置字段。

- id: config-editor
  name: '@deepseek-ai/dsh-config-editor'

普通字段保留加载器的正常生命周期。调用方可使用编辑接口提交完整配置。

## 理解实现

编辑器在派生候选配置前应用外部更改，与其他配置档操作共同锁定清单，并原子替换配置覆盖项。应用失败时恢复之前的文档并重新加载之前的补丁。本包不发布 invariant：加载器和持久化补丁拥有配置状态。

## 模型体验

通过面向模型的插件读取的配置值间接影响模型。改变请求前缀的消费者决定缓存影响。

## 已知限制

编辑写入当前配置档补丁。主目录补丁和命令行覆盖层参与优先级解析，但不作为写入目标。仅可编辑配置档根 Include 拥有且可唯一定位的条目。
